Using the default location.

Off puts every converted file directly in the converted output folder instead. This is a personal, local-only preference — it's not part of the shared default.

This only affects new conversions — files already sitting in their Author/Title folders are left alone, whichever way you flip this. If you move or flatten them yourself afterward, do it carefully: the app records each file's path in its own database, so that record goes stale the moment you move something outside the app, and two different books that happen to share a title would silently overwrite each other in a flat folder (the app checks for that automatically when it converts; a manual move gets no such check).
